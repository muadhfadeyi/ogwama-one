# OGWAMA One — Digital Proposal & Interactive Prototype

A simple digital partnership proposal and interactive web prototype for the **Ogun State Waste Management Authority (OGWAMA)**:

- **Welcoming Proposal Website:** [`proposal/OGWAMA-Digital-Transformation-Proposal.html`](proposal/OGWAMA-Digital-Transformation-Proposal.html)
- **Live Interactive Prototype (`OGWAMA One`):** [`prototype/index.html`](prototype/index.html)

## Key Capabilities Demonstrated
1. **Executive & PRS Overview** — Departmental lenses (*Finance, Commercial, Operations, PRS, Recycling*), live metrics, and compliance gap tracking.
2. **Instant Split-Payment Engine** — Pre-authorized gateway splits (**60/40** Industrial & Commercial, **80/20** Organised Estates & CDC Bulk with unit enumeration) and instant QR audit receipts.
3. **2027 Online Licensing Portal** — Replaces paper PDFs for PSPs, Waste Vendors (₦200k), and Special Permits, with automatic political-ward non-overlap and PSP/Vendor conflict locks.
4. **QR License Verifier & Recycling Compliance** — 3-second gate verification to stop unlicensed buyers and factory HSE double-crossing, plus Community Recycling Hub incentives.
5. **Political-Ward PSP Map & Citizen Desk** — Non-overlapping Ogun ward directory with direct Missed-Pickup and Waste Police dispatch.

## Run Locally
```bash
node server.js
```
Then open `http://localhost:8080`.
